|---|---|
| 엣지(`mysql-ai.company.local`) | HTTP 200 · 총 61.3s · **서버 보류 55.1s** |
| 공인 IP(`112.185.196.20`) | 동일 |

들어가 자동 회복한다.

## 표시 자체는 화면에서만 판정된다

자동으로 잠근 것: 요소 존재 · 배선 · 양쪽 상태 문구 · 클릭 시 모달 · 3시점 갱신 · 폴링 없음 ·
실패 시 침묵 · **인증과 동일 판정 함수 사용**.

마지막 항목이 이번 설계의 핵심이다 — 직전 cycle 에서 이 판정을 따로 썼다가 로그아웃 후에도
'연결됨' 이 됐다.

## 해소 조건

1. 로그인 직후(연결 전) → `○ 내 AI 연결 안 됨` 이 보이는가
2. 연결 정보 생성 직후 → `● 내 AI 연결됨` 으로 **즉시** 바뀌는가
3. 로그아웃 후 재로그인 → 다시 `○` 인가
4. 표시를 누르면 연결 모달이 열리는가
