### 미완: 브라우저 화면 판독

`bin/win-browser.py` 의 격리 프로필 세션이 배포로 끊겼고, 재발급을 시도하니
**`session-login`·`session-check` 가 CDP 브리지를 함께 닫아** `launch` → `session-login` →
`goto` 가 서로를 무효화했다(세 번 시도, 매번 `no_bridge` 또는 `authenticated: false`).
제품 결함이 아니라 검증 도구의 순서 의존 문제다.

**그래서 대체 검증으로 남긴 것이 위 표의 3행이다** — 화면에 표시되는 문안은 서버가 조립해
`body.handoff` 로 내려보내고, 프런트가 그것을 **그대로** 표시한다는 사실은 직전 cycle
(`TASK-20260828T120000`)에서 실화면으로 확인했다. 즉 "서버가 무엇을 렌더하는가" 를 확정하면
화면에 무엇이 뜨는지도 확정된다. 그 경로가 다시 갈릴 위험은
`test_every_surface_uses_the_server_composed_handoff` 가 잠근다.
