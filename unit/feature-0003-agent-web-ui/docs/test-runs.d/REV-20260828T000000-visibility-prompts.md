# Run — 가시성 · 프롬프트 · 제품

Environment: **Windows-browser 미수행** (relay 불가)

## 자동 검사가 닿지 않는 곳

- **말풍선이 실제로 바뀌어 보이는가** — 서버가 본문을 갱신하고 프런트가 국면 전환에 다시 읽는
  두 단계가 맞물려야 한다. 각각은 테스트로 잠갔지만 맞물림은 화면에서만 보인다.
- **운영자 지침이 답변에 반영되는가** — 프롬프트 맨 앞에 실린 것까지는 확인했으나, 그 지침대로
  답이 나오는지는 개인 AI 의 몫이다.

## 뮤테이션으로 확인한 것

| 뮤턴트 | 결과 |
|---|---|
| 시스템 프롬프트를 기본 지시 **뒤로** 이동 | KILL |
| 말풍선 교체에서 `placeholder` 술어 제거(남의 답변까지 덮기) | KILL |

두 번째가 특히 중요하다 — 술어가 넓으면 **이미 완성된 답변을 '처리 중' 으로 덮어쓴다.**

## 해소 조건

1. 질문 전송 → AI 가 가져가는 순간 말풍선이 **'조사·작성 중'** 으로 바뀌는가(새로고침해도 유지)
2. 연결이 없는 상태로 전송 → **'연결된 AI 가 없습니다'** 안내가 뜨는가
3. 제품별·역할별 지침을 설정한 뒤 질문 → 답변이 그 지침을 따르는가
4. 답변에 대상 제품이 표시되는가
