| 회차 | 화면이 말한 것 | 실제 |

| ④ **본 cycle** | **「내 AI 대기 중」** | 답할 수 없음 |

근본은 화면의 「준비됨」이 **「답할 수 있음」이 아니라 「하트비트가 살아있음」에서 파생**된다는
것이다. 그 **대리 지표를 준비됨으로 렌더하는 구조**가 거짓을 반복 생산했다 — 개별 회차를
고쳐도 축이 그대로면 다음 형태로 다시 나온다.

### 내가 절반만 배선해 둔 것

`TASK-20260903T140000` 에서 러너가 `ai_ready` 를 신고하게 만들었지만, **서버가 읽지도
저장하지도 않았다**(실측: `ai_ready` 문자열이 빌드 산출물에만 존재). 러너만 아는 사실이라
화면은 종전대로 거짓을 말했다. 사용자 지적이 정확히 그 공백이다.

## 3. 조치 — 전 구간 배선

| 층 | 무엇 |
|---|---|
| 스키마 | `WebOAuthTokens.RunnerAiReady`(TINYINT NULL) + `RunnerAiUnreadyReason` — **fast path** |
| 저장 | `oauth_store.set_runner_ai_health` — **throttle 없음**(전이가 늦으면 그 창에서 또 거짓) |
| 읽기 | `oauth_store.account_ai_health` — **tri-state**, 러너 선택은 지문 축과 동일 |
| 수신 | `ai_tools.bridge_heartbeat` 가 payload 를 읽어 저장(실패는 연결을 죽이지 않음) |
| 노출 | `oauth_as.connect_status` → `ai_ready` · `ai_unready_reason` (**접지 않고**) |
| 화면 | 칩 상태 「답할 수 없음」 + 사유 · 연결 모달 성공 판정에서 제외 |

### tri-state 를 보존한 이유

`None`(구 러너·컬럼 부재·듣고 있는 러너 없음)을 `false` 로 접으면 **구 러너 사용자 전원이
미연결로 보인다.** `RunnerBuild` 축이 이미 겪은 함정이고(그때는 「재설치하세요」를 멀쩡한
사용자에게 보냈다), 같은 실수를 반복하지 않는다. 화면은 `=== false` 로만 판정한다.

### 「답할 수 없음」을 「업데이트 필요」보다 먼저 그리는 이유

낡음은 「답은 오지만 옛 동작」이고 이것은 「답이 오지 않는다」다. 둘이 겹칠 때 사용자가 먼저
알아야 하는 것은 무거운 쪽이다.

## 5. 검증에서 배운 것

**초판이 낡음 판정 갈래 안에 조회를 넣었고 기존 테스트가 잡았다.** 그 갈래는
`test_staleness_predicate_has_exactly_one_home` 이 「판정 호출이 자기 갈래의 마지막이어야
한다」로 잠가 둔 자리다 — 뒤에 무엇이든 오면 판정을 덮을 수 있는 모양이 되기 때문이다.
남이 세운 불변식이 내 변경을 막아 준 사례이고, 그 자리를 이 cycle 의 테스트로도 함께 잠갔다.

**I7(죽은 가드)가 1차에 생존했다.** `aiReady === false && false` 로 분기를 죽여도 「문자열
존재」·「위치」 단정은 통과한다. 조건절을 정확히 잠그고 그 갈래가 문구를 대입하는지까지
보도록 좁혀 닫았다. ⚠ 그래도 **여전히 구조 단정**이다 — 더 강한 형태는 node 하네스로
`_paintConn` 을 실제 호출해 `textContent` 를 보는 것이고, 그 부재를 테스트 주석에 남겼다.

## 6. 이월 — 이 cycle 이 닫지 못한 「모른다」 창

**「모른다」를 여전히 준비됨으로 렌더한다.** 건강 상태는 fail-open 으로 시작하므로:

- 러너 기동 → 능력 협상 240초 진행
- **그 협상이 끝나기 전에** 온 질문은 아직 「건강함」 → 무제한 경로 → 라이브 실측 **200초 침묵**

사용자 보고(2026-09-03): *"이러한 이슈가 확인될 때 까지, 사용자는 200초동안 아무런 응답을
받지 못한 상태로 대기해야하는 불쾌한 경험을 얻었습니다."*

닫는 방향 두 가지(둘 다 미구현):

1. **협상 중 상태를 「확인 중」으로 노출** — 준비됨도 미연결도 아닌 제3상태. 그러면 그 창의
   질문에도 즉시 「아직 확인 중입니다」가 뜬다.
2. **호출 즉시 진행 표시** — 200초를 줄이지 못해도 **침묵은 없앤다**(경과 시간).
