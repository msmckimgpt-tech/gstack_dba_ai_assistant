앱을 설치하면 로그인부터 대화까지 그 창에서 끝납니다.

설치 파일을 확인하는 중입니다.

DQA 앱 받기

이 기기에서는 아직 설치할 수 없습니다

DQA 앱은 현재 Windows 10 · 11에서만 동작합니다. Windows PC에서 이 주소를 다시 열어 주세요.

공유받은 대화 링크는 이 기기의 브라우저에서도 그대로 열립니다.

지금은 내려받을 설치 파일이 없습니다

서버에 게시된 설치 파일이 없습니다. 관리자에게 문의해 주세요.

설치 파일 정보를 불러오지 못했습니다

네트워크나 서버 상태를 확인한 뒤 다시 시도해 주세요.

이미 설치했다면 설치한 DQA에서 열기. 아무 일도 일어나지 않으면 시작 메뉴에서 DQA를 실행하세요.

  1. 받은 파일을 실행합니다

    Windows가 “Windows의 PC 보호” 창을 띄우면 추가 정보 → 실행을 누르세요. 아직 코드 서명을 넣지 않아 처음 한 번 나타납니다.

  2. DQA 창에서 로그인합니다

    지금 쓰던 계정 그대로입니다. 설치한 뒤에는 이 브라우저로 돌아올 일이 없습니다.

  3. 다음부터는 시작 메뉴에서 엽니다

    바탕화면과 시작 메뉴에 DQA 아이콘이 생깁니다.
