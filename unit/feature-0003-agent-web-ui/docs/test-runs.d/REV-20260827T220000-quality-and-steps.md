# Run — 요청 품질 · 실행 단계

Environment: **Windows-browser 미수행** (relay 불가)

## 이 변경의 판정 기준

두 주장 모두 **화면에서만** 참·거짓이 갈린다:

1. 웹에서 고른 모델로 실제 답이 오는가(또는 못 맞췄다는 고지가 붙는가)
2. 'AI 추론' 탭에 도구 호출 단계가 보이는가

정적 검사는 "그렇게 쓰여 있다" 까지만 말한다. 특히 ②는 `meta.run_id` 와 `steps.run_id` 가
맞아야 화면이 찾는데, 그 연결은 **실제 조회 경로를 태워야** 확인된다.

## 자동으로 잠근 것

| 대상 | 검사 |
|---|---|
| 모델·추론 | task 적재 · claim 전달 · **러너의 CLI 인자화** · 폴백 시 고지 |
| 단계 | 원장 출처 · `run_id` 각인 · **사고 과정 비움**(`reason_source='none'`) · 진행 도구 필터 · 실패해도 전달 |

## 해소 조건

1. 컴포저에서 특정 모델·추론 강도를 골라 질문 → 답변이 그에 맞거나 **못 맞췄다는 한 줄**이 있는가
2. 답변 말풍선의 'AI 추론' 탭에 `list_schemas`·`execute_sql` 등 호출 단계가 뜨는가
3. 그 단계에 사고 과정이 **비어 있는가**(지어낸 텍스트가 없는가)
