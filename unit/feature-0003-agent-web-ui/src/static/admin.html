KB Curation

샘플 검수

사용자가 답변에 남긴 피드백(👍/👎 · "샘플 등록")이 검수 대기 큐에 쌓입니다. 검토 후 승인(KB 등록)하면 해당 질문↔SQL 쌍이 샘플 쿼리(sample_queries)로 승급되어 향후 답변 정확도에 반영됩니다. 거부하면 반영되지 않습니다. 생성 SQL 의 개인정보(PII)는 적재 시점에 자동 마스킹됩니다. 승급은 명시 검수만 가능합니다(자동학습 없음).

Metadata Governance

메타데이터

왼쪽 목록에서 항목을 선택해 수정하거나, 우측 상단 + 새 항목으로 추가하세요.

용어사전(도메인 용어↔정의)·ENUM 코드사전(컬럼 코드↔라벨)·테이블/컬럼 설명·샘플쿼리를 데이터소스별로 관리합니다. 등록 내용은 질문/스키마 매칭 시 답변 프롬프트에 주입되어 정확도에 직접 반영됩니다. 공용(common) 스코프는 모든 데이터소스에 적용됩니다. 부정확한 등록은 답변 품질을 저해할 수 있으니 신중히 관리하세요.

상단에서 특정 데이터소스 스코프를 선택하면 해당 스키마 골격을 가져올 수 있습니다. 공용(common) 스코프는 실제 스키마가 없어 골격을 가져올 수 없습니다.

현재 스코프 데이터소스(—)의 실제 스키마에서 테이블/컬럼 골격을 가져와 설명만 채워 일괄 저장합니다. 골격은 저장 전까지 영속되지 않습니다(미영속). 큰 스키마는 가져오는 데 시간이 걸릴 수 있습니다.

테이블 컬럼 용어 스키마 카드(클릭=펼침) 스키마 클러스터 신뢰 관계 추정 관계 AI 분석 중 AI 분석됨 크기·라벨% = 검색 유사도(pg_trgm) · 실선=검증 관계 · 점선=암묵 추정(사용·프로브 강화/파단) · 주황 점선=AI 분석중 · 보라 테두리=AI 능동분석 완료

노드를 한 번 클릭하면 해당 테이블/컬럼/용어의 설명·컬럼·관계·연관 용어를 여기에서 봅니다.

더블클릭하면 그 노드 중심의 이웃 그래프로 펼쳐집니다. 우클릭하면 상세 보기·관계 상세(방향·신뢰도·근거)·관계 확장(1~3-hop)·중심 보기 등 상호작용 메뉴가 열립니다. 그래프는 관계형 메타데이터를 Apache AGE 로 투영한 읽기 전용 뷰입니다(편집은 다른 서브탭).
