  `_ssrf_check_host` 가 (True, pin) 반환 → caller 가 169.254.169.254 로 연결(메타데이터 SSRF).
  §12.3 sign-off 의 핵심 불변식("메타데이터는 토글 무관 차단")이 거짓. Action: `ip.ipv4_mapped`
