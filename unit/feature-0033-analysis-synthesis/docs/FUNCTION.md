# Function: 클러스터 합성 요약 (L2)

## 개요

의미 클러스터마다 **"이 묶음이 함께 무엇을 하는가"**를 2~4문장 한국어로 합성해
`cluster_summaries` 에 적재한다. 라벨(평균 9자)이 이름이라면 요약은 설명이다.

라이브 실측(2026-07-30): 테이블 클러스터 **818개** · 멤버 15,365개 · 평균 18.8 · 최대 1,300.
각 클러스터에 라벨만 있고 요약이 없어, 전역 질의는 개별 분석문을 훑을 수밖에 없었다.

## 1. 클러스터 정체성 = 멤버셋 지문

`semantic_cluster_id` 는 pass 마다 MDS 배치 순서로 재부여되어 churn 한다. 좌표를 캐시 키로
쓰면 내용이 그대로인데도 매 pass 818개를 재생성한다. 그래서 PK 는
`(scope_key, schema_name, member_set_hash)` 다. `cluster_id` 는 표시·조회 편의로만 함께 저장한다.

## 2. 캐시 키 — 3중 일치

| 축 | 의미 | 변하면 |
|---|---|---|
| `member_set_hash` | 클러스터 정체성(멤버 키 집합) | 다른 클러스터로 취급 |
| `l1_version` | 멤버 분석문(L1) 지문 | 분석이 갱신됨 → 요약 재생성 |
| `evidence_version` | 멤버 통계 증거(L0, feature-0031) 지문 | 증거가 갱신됨 → 요약 재생성 |

셋 다 같을 때만 캐시 적중이다. **증거·분석의 변화가 요약에 전파되는 유일한 경로가 이 키다.**

### ⚠ 시그니처 미유입 불변식

요약은 `build_table_signature_text` 에 **절대 들어가지 않는다**. 들어가면
요약 갱신 → 시그니처 변경 → 재임베딩 → 재클러스터 → 요약 갱신의 순환이 생긴다.
테스트가 시그니처 빌더 소스에 요약 참조가 없음을 단정한다.

### 결정적 정렬

`_version_hash` 는 입력을 **정렬 후** 해시한다. 멤버명·분석문도 정렬해 payload 에 넣는다.
정렬이 빠지면 같은 클러스터가 pass 마다 다른 지문을 받아 캐시가 매번 미스 나고 요약이 무한
재생성된다(현행 라벨 payload 가 `ORDER BY` 없이 겪던 문제와 같은 계열).

## 3. 생성 시점 — 일관성 경계

클러스터가 **확정된 직후**(병합·재정렬·라벨 확정·`_disambiguate_labels` 이후)에 생성한다.
그 시점의 멤버셋이 곧 저장되는 `member_set_hash` 이므로, 요약이 가리키는 대상과 캐시 키가
정확히 일치한다. 이후 pass 가 다른 멤버셋에 도달하면 해시가 달라져 자연히 재생성된다.

## 4. 비용 경계

| 장치 | 값 |
|---|---|
| pass 당 신규 생성 상한 | 40 (818개를 여러 pass 에 나눠 채운다) |
| LLM 배치 크기 | 6 (라벨용 40 은 요약엔 과다 — 응답이 길다) |
| payload 멤버 상한 | 24 |
| payload 분석문 상한 | 8 |
| 상위 게이트 | 백그라운드 토큰 예산(feature-0032) · `acquire("llm")` · task 예산 · kill-switch |
| 정지 스위치 | `AGENT_METADATA_CLUSTER_SUMMARY` (콘솔 live) |

상한에 걸릴 때는 **멤버가 많은 클러스터부터**(도메인 파악 기여가 크다), 동률은 해시 순(결정적).

## 5. 실패 격리

- LLM 실패 → 그 pass 만 중단, 앞서 성공한 요약은 유지(부분 성공).
- 빈약한 응답(20자 미만) → 저장하지 않는다. 저장하면 캐시가 적중해 영원히 그 상태로 굳는다.
- 요약 경로 전체가 예외를 내도 **클러스터링·라벨 역기록은 정상 진행**한다(부가 산출물).
- 캐시·증거 조회 실패(테이블 부재 등) → 빈 결과로 진행(fail-soft).

## 6. 정직성 — `analyzed_count`

커버리지가 14.6% 인 현실에서 "멤버 20개 클러스터를 요약했다"와 "그중 3개만 상세분석이 있었다"는
전혀 다른 신뢰도인데 요약문만 보면 구분할 수 없다. 그래서 `member_count`/`analyzed_count` 를
함께 저장하고 payload 로도 전달한다. 프롬프트는 근거가 적을 때 **일반적으로 서술**하되
"정보가 부족하다"는 변명 문장은 쓰지 않도록 지시한다(그 사실은 카운트가 말한다).

## 7. 이 기능이 하지 않는 것

- **표시하지 않는다** — 저장까지가 범위다. 그래프 뷰·대화 grounding 주입은 ITEM-08/09 소관.
- **라벨을 대체하지 않는다** — 라벨은 그룹 헤더 칩(32자 규율), 요약은 설명. 둘은 공존한다.
- **routine 클러스터는 아직 대상이 아니다** — 1차는 테이블 클러스터.
