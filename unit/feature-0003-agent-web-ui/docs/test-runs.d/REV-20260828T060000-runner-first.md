# Run — 러너 기본화

Environment: **Windows-browser 미수행** (relay 불가)

## 라이브 원장이 한계를 증명했다

```
15:32:25  wait 55.2s → 0건
   …          (10회)
15:41:08  wait 55.1s → 0건
15:42:09  wait 53.1s → 1건   ← 질문 수신
          (이후 호출 없음 · claim 없음 · task 방치)
```

대기 1회 = AI 의 도구 호출 1회. 대화형 세션의 턴 예산이 그것을 감당하지 못하고, **질문을 받은
그 순간** 끝났다. 화면 없이도 결론이 나온 드문 경우다.

## 화면에서만 판정되는 것

- 재시작 후 표시가 `◐ AI 대기 안 함` 으로 바뀌는가
- 그 표시를 눌러 재연결 → `● 내 AI 대기 중` 으로 돌아오는가
- `--resume` 이 실제로 복귀시키는가(설정 파일 존재·토큰만 새로)

## 이번 cycle 에서 테스트가 실제로 잡은 것

rebase 중 stash 충돌로 `connect_status` 의 `listening` 반환이 **유실**됐다. 테스트가 그것을
잡았다 — 눈으로 훑었다면 "고쳤다고 기억하는" 코드를 다시 확인하지 않았을 것이다.
