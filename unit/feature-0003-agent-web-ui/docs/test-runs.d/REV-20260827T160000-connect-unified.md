# Run — 연결 화면 단일 흐름

Environment: **Windows-browser 미수행** (relay 불가 — 사유는 `REV-20260827T000500-bridge-poll-ui.md`)

## 대체 검증

브라우저 없이 확인한 것:

| 대상 | 방법 |
|---|---|
| 지시문 실제 생성물 | `handoff()` 를 격리 실행해 **완성된 텍스트를 눈으로 확인** (JSON 설정·URL·토큰 자리·도구 순서) |
| 방법 순서 A→B→C | 소스에서 인덱스 비교 + C 에 '허용'(사람 개입) 명시 확인 |
| 단일 흐름 | 화면 텍스트(주석 제외)에 `방법 ①/②`·`connectAuto`/`connectManual` 부재 |
| DOM 계약 | JS 가 참조하는 id 가 HTML 에 전부 존재 |
| HTML 유효성 | 파서 통과 |

지시문을 **렌더해서 확인**한 것이 이번 검증의 핵심이다. 문자열 조각을 각각 단언하면
"조각은 다 있는데 합쳐 놓으니 말이 안 되는" 결과를 놓친다.

## 미검증 — 이것이 진짜 성공 기준

**실제 AI 가 이 지시문을 받아 연결에 성공하는가.** 그리고 A·B·C 중 무엇을 고르는가.
자동 검증은 "지시문이 그렇게 쓰여 있다" 까지만 말할 수 있고, AI 가 그것을 읽고 올바로
행동하는지는 실사용만 답한다.

해소 조건:
1. `/ai/connect` → [연결 정보 만들기] → [복사]
2. AI(Claude Desktop / Claude Code)에 붙여넣기
3. **사람이 추가로 아무것도 하지 않아도** 연결되는가
4. 연결 후 대기 중인 질문 2건을 스스로 가져가 처리하는가
