## Findings (P2 7건)

1. **구문 색 토글이 스크롤을 최상단으로 되돌린다** — `render()` 가 scroller 를 새로 만드는데
   `_captureScrollAnchor`/`_restoreScrollAnchor` 를 호출하지 않는다. 같은 파일의 다른 렌더 경로는
   전부 앵커를 뜬다. 원문 뷰는 축약이 없어 항상 전량(최대 6,000행)이라 잃는 거리가 diff 보다 크다.
   (비교 모달 AC-AVD-15 · 주석 "스크롤 보존 계약은 다른 토글들과 동일해야 한다" 를 인용한 채 절반만 옮겼다.)
2. **503 전용 문구가 도달 불가 dead code** — `apiFetch` 는 non-2xx 를 throw 하고 메시지를
   `payload.error || payload.detail || statusText` 로 고른다. 503 payload 에 `error` 가 없어 사용자는
   `Service Unavailable`(HTTP/2 면 빈 문자열)을 본다. 하네스 stub 이 **항상 resolve** 해 vacuous pass.
   `/diff` 도 동형(선행 결함을 그대로 복제).
3. **파일명 드래그 선택이 모달을 연다** — click target 은 mousedown/mouseup 의 **공통 조상**이라
   드래그 후 손을 떼면 행으로 승격된다. `modal-dismiss.js` 가 배경 dismiss 에서 봉인한 **같은 기전**.
4. **`role="button"` 안에 버튼 3개 + 이름이 행 전체 텍스트** — ARIA children-presentational 로
   ⬇·🗑·버전 토글 시맨틱이 가려질 수 있고, 낭독 이름이 "📎 report.csv v2 … ⬇ 🗑, 버튼" 이 된다.
5. **다중 버전에서 "어느 버전인가" 가 화면에 없고 구버전 원문 경로가 실재하지 않는다** —
   `composer.js` 주석("버전 선택기") ↔ `attach-diff.js` 주석("두지 않는다")이 정면 충돌하고,
   docstring 이 주장하는 "그 버전의 id 로 연다" 의 진입점이 UI 에 없다.
6. **절단인데 제목·통계가 "원문" 단정 유지** — 형제 화면(`_identicalFlags`)이 명시적으로 금지한 것.
7. **모달 포커스 이동·복귀 부재** — 이번 cycle 이 처음으로 "키보드로 여는 모달" 을 만들었는데
   포커스가 뒤에 남고 트랩도 없다. 같은 feature 의 첨부 관리 모달은 이미 opener 저장·복귀를 한다.
