내 AI를 이 서비스에 연결하면 질문에 답할 수 있습니다. 아래 연결 준비를 누른 뒤 내 AI 실행을 누르면 연결 프로그램이 열리고 나머지는 그 창에서 끝납니다.

터미널 없이 연결하기 — 연결 프로그램을 받아 실행하면 설치·로그인·연결을 창에서 끝낼 수 있습니다.

연결 프로그램 받기

    터미널로 연결하기 — 연결 프로그램을 아직 설치하지 않았다면

    내 컴퓨터의 터미널에 그대로 붙여넣고 실행하세요.

    실행이 끝나면 대화 화면 왼쪽 아래 계정 옆 표시가 대기 중으로 바뀌고 입력창이 열립니다.

    환경을 잘 모르겠다면 — AI에게 조사만 맡기기

    아래 내용을 내 컴퓨터의 AI(Claude Code · Codex 등)에 붙여넣으세요. AI가 이 머신의 파이썬·AI CLI를 조사해 빈칸만 채우고, 설치와 검증은 1단계와 똑같은 스크립트가 합니다. AI가 고른 값은 화면에 그대로 표시되고 범위를 벗어나면 스크립트가 버립니다 — 다만 어떤 값을 고르는지는 AI마다 다를 수 있습니다.

    터미널을 쓸 수 없다면 — AI에게 전부 맡기기

    아래 내용을 AI에 붙여넣으세요. 연결 방식 선택과 인증은 AI가 판단합니다 — 도구에 따라 설치 결과가 달라질 수 있습니다.

    연결 정보에는 토큰이 들어갑니다. 내 권한으로 데이터를 조회하므로 비밀번호처럼 다루고 남에게 주지 마세요.

    로그아웃하면 무효가 되고, 이 화면을 벗어나면 다시 볼 수 없습니다.

    먼저 로그인하세요.
