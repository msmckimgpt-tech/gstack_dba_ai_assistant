### 3. Challenge to current spec

「도구의 구문 = 식별자 + 인자 표기 전부」라는 독해는 census 밖 도구를 **정보량 0** 인 행으로
만든다. 라벨 표를 영원히 census 와 동기화한다는 전제 위에서만 이 교환이 성립하는데, 그
동기화 장치가 지금은 정규식 census 다. 또 「표시층 전용 정화」 결정은 정화 지점이 늘 때마다
누락 위험을 만든다 — 이번 cycle 에서만 3곳으로 갈렸고 그중 둘이 다른 파생 함수를 타서 제목
불일치가 남았다. 표시용 단계를 만드는 **단일 seam** 을 두고 모든 경로가 그것만 부르게 하면
새 경로가 생겨도 가드의 모수가 자동으로 따라간다.
