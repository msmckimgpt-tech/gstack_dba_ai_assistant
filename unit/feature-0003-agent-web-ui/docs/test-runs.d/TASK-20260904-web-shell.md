### 7번의 의미 (잔여 항목이었다)

종전에는 WSL 런타임을 `--cmd` 로 넘겨서 러너가 **능력 협상을 돌지 않았고**, 답변은 정상인데
웹의 「답할 AI 있음」이 ❌ 로 남았다. 러너가 WSL 자리를 직접 알게 되어 `--ai claude` +
`BRIDGE_AI_PATH_CLAUDE` 만으로 연결되고, 협상이 정상으로 돈다.

실측 체크리스트: `connected:ok · listening:ok · ai:ok · answered:pending`
(`answered` 는 아직 질문하지 않았으므로 pending 이 옳다.)

### ⚠ 검증 환경의 인공물 (결함 아님)

앱 창은 Chrome **기본 프로필**로 열리는데 이 검증의 로그인 세션은 릴레이 전용 프로필에 있다.
그래서 앱 창 캡처에는 로그인 화면이 나온다. 실사용자는 자기 기본 프로필로 서비스를 보다가
[내 AI 실행] 을 누르므로 세션이 그대로 따라온다. 패널 동작 검증은 세션이 있는 릴레이
브라우저에서 **같은 브리지**에 붙여 수행했다.
