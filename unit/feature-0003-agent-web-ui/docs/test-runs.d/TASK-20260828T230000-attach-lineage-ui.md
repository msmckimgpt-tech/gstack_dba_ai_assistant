# TASK-20260828T230000 — 첨부 계보 UI (단건 계보 비교 + 목록 계보 표시)

## 1. 제보와 진단

> "단 건 계보일 경우, 모달 창에서 버전 비교를 진행할 수 있는 수단이 없는 이슈가 확인되었습니다.
> 또한, 첨부 파일 목록에서도 각 계보 내 어떤 파일들이 구성되어 있는지 명시적으로 드러나지
> 않습니다."

두 이슈 모두 **계보 분기**(REQ-20260814)가 만든 UX 구멍이다. 분기 결정 자체는 옳다 — 사람이
올린 최신본을 AI 가 supersede 하지 않는다. 문제는 **화면이 그 구조를 감췄다**는 것이다.

**게이트가 두 겹이었다**(이것이 진단의 핵심):

| 층 | 종전 조건 | 결과 |
|---|---|---|
| 버전 펼침 토글 | `verCount > 1` | 분기 계보(v1 뿐)는 토글이 안 뜬다 |
| 비교 버튼 | `versions.length > 1` | 토글이 없으니 버튼은 화면에 **존재하지도 않는다** |

비교 버튼만 고쳤다면 화면은 그대로였다. 모달은 이미 계보 축을 지원했고(`hasLineageAxis`),
말풍선 칩도 이미 고쳐져 있었다 — **목록만 뒤처진 비대칭**이었다.

### 단건 계보(계보 2/3) 비교

- 버전 박스: 버튼 `⇄ 계보 비교` · title "이 계보는 버전이 하나입니다 — 같은 이름의 다른
  계보(2개)와 비교합니다"
- 계보 안내: "이 계보: AI가 만든 계보 · 다른 파일에서 갈라짐 · 파일 1개 / 같은 이름의 다른 계보 2개"
- 모달: 제목 **「계보 비교」** · 축 `계보 간(시간순)` 활성 · 선택지 3개(사용자 업로드 v1 /
  AI 수정본 v1 · 현재 / AI 수정본 v4) · 실 diff 렌더 `LIMIT 50;` → `LIMIT 500;`

### 서버 payload

```
1246 sample.sql v1 user      cnt=1 lineage_from=None
1247 sample.sql v1 assistant cnt=1 lineage_from=1246
1256 sample.sql v4 assistant cnt=4 lineage_from=1246   ← root(1249) 에서 해소
```

1차 구현은 **행 단위** 표식만 실어 `1256`(v4 head)이 `None` 이었다 — 분기 표식은 head 가 아니라
그 계보의 **root** MetaJson 에 있다. 라이브 payload 확인이 잡았다.
