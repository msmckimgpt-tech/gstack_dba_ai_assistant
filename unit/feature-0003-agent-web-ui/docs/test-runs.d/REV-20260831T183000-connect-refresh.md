## 실측 중 겪은 것 — 침묵한 예외는 추적할 수 없다

판정이 `false` 로 나오는데 이유를 알 수 없었다. `except Exception: runner_stale = False` 가
완전히 침묵했기 때문이다. 로그를 넣어 보니 예외가 아니라 **상주 프로세스가 옛 모듈을 들고
있던 것**이었다(파일은 최신, 프로세스는 기동 시점). 사용자에게는 조용하되 로그에는 남기도록
고쳤다 — 이 자리가 정확히 로그가 필요한 자리다.
