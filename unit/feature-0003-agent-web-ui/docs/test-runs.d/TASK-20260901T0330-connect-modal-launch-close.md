성공 분기의 창-세대 검사를 지운 뮤턴트가 **처음엔 생존했다** — F3(창 교체)는 `_connSeq` 가 먼저
걸러 그 분기에 도달하지 않기 때문이다. 「방어는 넣었는데 그것을 겨누는 단언이 없다」는 codex 2R
지적의 형태를 그대로 반복한 것이고, 뮤테이션이 그것을 잡았다. F4(「실행 대기 중 창을 **닫기만**
했을 때 뒤늦게 도착한 성공이 토스트를 띄우는가」)를 신설해 KILL 을 확인했다.
