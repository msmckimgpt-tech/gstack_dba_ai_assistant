갈라 보니 **원인은 남아 있던 `msedgewebview2.exe` 가 사용자 데이터 폴더를 잡고 있던 것**이고,

대조군(허용적인 로컬 서버)을 같은 페이지에서 함께 불러 갈라낸 것이 판정을 뒤집었다.
