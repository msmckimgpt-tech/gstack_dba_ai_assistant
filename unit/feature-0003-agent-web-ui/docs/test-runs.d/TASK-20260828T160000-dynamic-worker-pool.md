| 계약 | 관측 |
|---|---|
| **시작 1개** | 기동 로그가 "동시 1건에서 시작" 을 그대로 말한다 |
| **수요 확장** | `동시 요청 1건(진행 중 1) — 슬롯 1개 확장, 동시 처리 2건` |
