#### ⑤ 신규 발견 — TASK-0300 권한상승 가드 × `model.access.*` **자기 잠금 경로**

- **원인**: `admin_accounts.py` TASK-0300 (REQ-0287) privilege-escalation 가드 —
  *"본인이 보유하지 않은 권한은 설정할 수 없습니다"*. ③ 에서 자기 계정에 opus 를
  `deny` 로 걸어둔 상태였으므로, actor 가 **미보유** 권한을 역할에 부여하려 한 것으로
  판정돼 정상 차단됐다.
- **성질**: 결함이 아니라 **기존 가드가 새 동적 그룹에 그대로 적용된 결과**이며,
  `product.access.*` 도 동일하게 동작한다. 다만 모델 권한에서는
  **"관리자가 자기 자신에게서 모델을 해제하면, 그 모델을 자신에게도 타 역할에게도
  다시 부여할 수 없다"** 는 자기 잠금(self-lockout) 경로가 된다.
- **탈출구**: (a) 해당 모델을 보유한 **다른 관리자**가 복구, 또는
  (b) DB 에서 override 행 삭제. 본 검증에서는 (b) 로 복구했다
