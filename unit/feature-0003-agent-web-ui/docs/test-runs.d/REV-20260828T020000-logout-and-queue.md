# Run — 로그아웃 · 적재 정책

Environment: **Windows-browser 미수행** (relay 불가)

## 브라우저 없이 실증한 것

이번엔 결함 자체를 **라이브 데이터로 직접 보였다** — 화면 없이도 갈림이 드러났다:

```
구 술어(토큰 행만)     → 연결 1건   ← 화면이 본 것
신 술어(세션 포함)     → 연결 0건   ← 실제(인증은 401)
```

그리고 배포본에서 동작을 확인했다: 세션 revoke 후 `resolve_access_token` → **거부**.
즉 인증 경계는 처음부터 지켜졌고, 틀린 것은 표시였다.

## 뮤테이션

| 뮤턴트 | 결과 |
|---|---|
| 연결 판정에서 세션 조건 제거 | KILL |
| 로그아웃의 revoke 전파 제거 | KILL |

## 해소 조건 (사용자 테스트)

1. 로그아웃 → 다시 질문 → 안내가 **"연결되어 있지 않습니다"** 인가
2. 그 질문이 **대기열에 안 들어가는가**(연결 후 밀린 것이 쏟아지지 않는가)
3. 연결 후 다시 질문 → 이전 질문이 **문맥으로 함께** 가는가
