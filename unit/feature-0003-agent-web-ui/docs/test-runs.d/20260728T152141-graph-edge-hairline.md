#### 3. 채택 — hairline 처리(지도·CAD 렌더러 표준: Mapbox GL·deck.gl·Skia/Cairo 동일 원리)

폭이 1물리픽셀 미만이면 **폭을 정확히 1물리픽셀로 올리고, 모자란 두께분을 alpha 에 곱한다**.

```
if (w_screen < 1/dpr) { alpha *= w_screen · dpr; w_screen = 1/dpr; }
```

- 커버리지가 균일해져 끊김·밝기 계단이 **원천 소멸**한다.
- 시각적 '가늘기' 는 alpha 가 연속 표현하므로 "가느다랗게" 요구가 그대로 유지된다.
- 비용은 산술 몇 줄 — MSAA 증설·resolution 상향 같은 전역 비용이 없다.
- 트레이드오프: 서브픽셀 구간에서 굵기(개수 축) 일부가 alpha(신뢰도 축)와 곱해진다. 다만 그 구간은
  애초에 굵기 차이를 눈으로 분해할 수 없어, alpha 로 옮기는 편이 정보를 **더** 보존한다.
  1물리픽셀 이상 구간에서는 두 축이 종전대로 분리된다.

**base 재조정 동반**: 기본 굵기 0.6 → **1.0px**(개수 축 1.00 / 4건 1.54 / 16건 2.08 / 64건 2.60 포화).
0.6px 는 dpr 1 에서 항상 hairline 경로를 타 개수 축이 상시 alpha 로 흘렀다. 1.0px 부터 정상 렌더 구간이라
두 축이 설계대로 분리된다. 1px 실선은 hairline 과 같은 두께라 "가늘다" 는 인상도 유지된다.
