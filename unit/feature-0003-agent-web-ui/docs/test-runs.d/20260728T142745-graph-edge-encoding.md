#### 3. 인코딩 축 재배치 (사용자 지정)

채널을 직교화해 **하나의 시각 속성이 하나의 의미만** 담게 했다.

| 채널 | 의미 | 값 |
|---|---|---|
| **굵기** | 관계의 **개수** | 1건 0.60px · 4건 1.10 · 16건 1.60 · 64건 2.10 · 이상 2.20 포화 (로그) |
| **진하기** | 연결의 **신뢰성** | trusted 0.85 > 루틴(확정 참조) 0.72 > candidate 0.5 > 교차DB 0.5 > inferred 0.38 |
| 색 | 관계 종류 | FK 갈색·후보 골드·추정 슬레이트 / 루틴 보라 / 교차DB 마젠타 / 스키마 집계 슬레이트 |
| 화살촉 | 방향 | 읽기=테이블→루틴, 쓰기=루틴→테이블 |
| 곡률 | 왕복 분리 | 진행방향 왼쪽 고정 |

- **기본은 가느다랗게** — 단일 관계선 0.6px(종전 신뢰도별 0.75~1.6px).
- **다발(strands) 제거** — 개수를 굵기가 담게 되어 중복 인코딩이고, 줌아웃에서 화면을 더 가렸다.
  종전 §83 의 '부모 볼륨=가닥' 은 §86 의 '개수=굵기' 로 통합된다.
