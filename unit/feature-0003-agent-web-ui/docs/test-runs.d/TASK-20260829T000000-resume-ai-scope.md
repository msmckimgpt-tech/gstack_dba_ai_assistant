## Windows-browser 시각검증 미수행 — 사유

`static/` 아래 파일이 바뀌었으므로 형식상 대상이지만, 이 파일은 **브라우저가 렌더하는 자산이

포함되는가" 하나이고, 그것은 브라우저가 아니라 **러너 재기동 로그로 검증된다**.

## 라이브 실측 (이 결함이 드러난 경로이자 검증 경로)

P0-Z4 배포 후 재기동:

```
[bridge] AI = claude
[bridge] 쓸 수 있는 모델·추론 수준을 물어보는 중… (claude — 최초 1회, 수십 초)
[bridge]   claude: 모델 4종 · 추론 5단계 (본인 응답)
[bridge] 고를 수 있는 것: Claude(4종, 추론 5단계)      ← codex 가 없다
```

`config.json` 을 확인하니 `ai: "claude"` 가 저장돼 있었다 — 사용자가 `--ai` 를 준 적 없는데도
첫 기동의 자동 감지 결과가 굳었고, `--resume` 이 그것을 상속해 신고 목록을 좁혔다.

**단위 테스트로는 보이지 않는 종류다.** 각 함수는 스펙대로 동작했고, 어긋난 것은 *값의 수명*
이었다 — 저장하고 · 재기동하고 · 상속받아야 드러난다.

수정 후 재기동에서 두 런타임이 모두 신고되는지는 **배포 후 재기동으로 확인한다**(이 fragment 에
Run 을 추가한다).
