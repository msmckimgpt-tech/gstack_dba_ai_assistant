이 판단에는 직접 근거가 있다 — 직전 cycle(TASK-20260828T120000)에서 **소스 테스트는 전부

아니라 **AI 가 내려받는 파이썬 스크립트**다. 픽셀 변화가 없고, 정본과의 해시 일치는 단위
