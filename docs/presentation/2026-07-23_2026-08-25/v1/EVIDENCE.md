### U-001 · 직전 보고 미결 3건 — 이번 기간에도 이월 (핵심)

- **가진 것 / 없는 것**: 있음 = 접지 축 코드 권위선 복구·라이브 모순 제거. 없음 = 구조 일반해·운영 정책 결정.
- **확인 방법**: 전역 지침의 권한 범위를 정책으로 확정(전면 대체 금지 / 병합 / 코드 우선 중 택일).

## 3. 특별 주의 항목 (단정 절대 금지 — §1/§2 로 분류 완료)

- **실제 배포 여부**: 본 원장의 "배포 완료"는 **서비스 실환경에 반영되고 배포 후 실측이 기록된 것**을
  뜻한다(기록된 배포 커밋·서비스 빌드 식별자 일치 확인·배포 후 실측 기록 존재). 다만
  **운영 배포 로그 원장 자체는 본 원장에 인용하지 않았다** — 근거 종류는 머지·배포 기록·배포 후
  실측 문서다. 서비스는 실사용 중이나 **연결 대상 데이터 범위는 U-001 ③에 따라 제한적**이다.
- **테스트 결과**: PASS = 단위·통합 스위트, 적대 검증 패널, 실 브라우저 육안 검증을 뜻한다.
  미검증 = U-003 ~ U-007.
- **성능 개선 수치**: E-000b(13초→0초 = **엣지 접속 로그**, 전후 동일 규모 창) ·
  E-000c(−25~35초 = **서버측 응답 경로**, 평균 141초 분해 기준) · E-022(동기화 63% 무변경 = 서버측) ·
  E-015(주입 지연 99.4ms = 서버측). **브라우저 체감·대규모 프레임레이트는 미측정(U-006)**.
  측정 위치·조건을 항상 병기한다.
- **장애 재발방지 효과**: 가드·게이트 도입까지 확인. **재발 0 실증은 U-004**(관측 이연).
- **화면 변경 전후 자료**: 덱에 실측 화면 캡처를 첨부하지 않았다 → 전/후는 **업무 관점 개념 도식**
  (인라인 SVG)으로 재구성하고 각 도식에 "실제 화면 대신 개념 도식"을 명시했다.
- **문서-코드 불일치(conflict)**:
  - **C-1**: 사용자 대면 릴리즈노트 정본이 두 곳으로 갈려 있다 — 운영자·개발자용 문서는 07-10 이후
    미갱신이고, 실제 사용자 게재분은 제품 내 원장에 있다(§0-B 정정 기록). 발표에는 후자를 썼다.
  - **C-2**: 기능 현황 인덱스의 `in-progress` 라벨 ↔ 실제 배포 완료 불일치 → U-009.
  - **C-3(청중 비노출)**: 마찰 원장에 식별자 중복 3건이 있어 인용 시 제목으로 식별해야 한다.
  - **C-4(청중 비노출)**: 일부 기능 번호가 코드 거주지와 다른 cross-cutting 라벨이다.
  - **C-5**: 한 기능 단위의 이름이 기각된 초기 후보에서 유래해 **이름과 실제 산출물이 어긋난다**
    (개명 마찰이 더 크다고 판단해 유지 — 기록에 명시됨).
- **결정이 뒤집힌 기록(정직성 재료 — 지우지 않고 보존)**: 첨부 삭제(도입 → 같은 날 철회 → 재도입) ·
  자동 로컬 모델 강등(비용 절감 결정 → 전면 폐지) · 배포 게이트(정적 대기 → 교대 방식).
  각각 "그때는 왜 맞았고 지금은 왜 아닌가"가 의사결정 문서에 남아 있다.
