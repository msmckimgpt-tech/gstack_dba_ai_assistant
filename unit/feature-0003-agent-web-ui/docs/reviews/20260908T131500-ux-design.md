    제보 대상은 MSSQL 객체인데 백틱은 MySQL 인용 문법이라 「틀린 구문」으로까지 읽힌다.

  - Reason: §16.8 B-2 는 「사용자의 어휘로 판정하라」이지 「식별자만 지워라」가 아니다.

### 3. Challenge to current spec

중복 라벨 2쌍(`describe_schema`/`list_tables`, `read_attachment`/`read_task_attachment`)은
결함이 아니라 B-2 를 제대로 적용한 결과다 — 배지는 「어느 모듈이 돌았는가」가 아니라 「무슨
일이 일어났는가」를 말해야 한다. 다만 실제 노출면은 ①배지 ②제목 ③제목 안의 인용 문자
④근거 줄의 유무 ⑤진행/완료 동일성 **다섯 축**이고, ③④⑤가 열린 채 ①②만 닫으면 사용자는
같은 화면을 다시 캡처해 보낸다. 배지 텍스트 예산(한글 5자 ≈ 64px)도 주석이 아니라 테스트로
못박기를 제안한다.
